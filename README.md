# MyPassword (单机离线密码管理器)

一款安全、离线的 Android 密码管理与一站一密生成工具。

## 核心特性

- **一站一密**：只需牢记一个主密码，通过「主密码 + 站点标识」确定性推导出各站点唯一强密码。
- **纯离线运行**：无需网络权限，密码由算法即时计算得出，本地不保存任何生成的明文密码。
- **本地加密存储**：支持保存不同站点的密码长度与个性化备注，备注数据使用 Android Keystore 硬件级 AES-256-GCM 密钥加密。
- **安全迁移**：支持导出和导入 `.mpbackup` 加密备份文件，备份使用 PBKDF2 强化派生密钥加密，方便设备间迁移。

## 使用指南

1. **设置主密码**：初次打开应用时，根据提示设置并确认主密码（请务必牢记，主密码不可找回）。
2. **生成密码**：
   - 输入验证主密码进入主界面；
   - 在「输入内容」中填写站点名称或标识（如 `github`、`google` 等）；
   - 选择密码长度（8~12 位），点击「生成密码」；
   - 长按生成结果即可复制。
3. **保存与检索**：
   - 点击「保存记录」可将当前站点的密码长度偏好与备注保存至本地；
   - 点击右上角菜单可选择「按备注检索」，快速查找已保存的站点。
4. **数据备份与恢复**：
   - 右上角菜单 ->「设备迁移」->「导出备份 / 恢复备份」。

## 源码编译与开发

> **提示**：本项目为 Android Studio 工程，项目根目录位于 `MyPasswordModern` 文件夹。

- 打开方式：启动 Android Studio，选择 **Open**，定位并打开项目子目录 `MyPasswordModern`。
- 构建环境：JDK 17+，Android SDK 36。
